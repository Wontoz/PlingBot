# PlingBot

Discord bot that tracks a Swedish betting coupon (Stryktipset / Topptipset / Europatipset) live — announces goals, red cards and VAR events, and keeps a live dashboard updated. Comes with a companion web dashboard for following the whole round, including per-match statistics, events and lineups.

![PlingBot icon](https://github.com/Wontoz/PlingBot/blob/main/assets/icon1024.png)

---

## What's in here

- **PlingBot** — the Discord bot. Polls live scores, announces goals/cards/VAR, keeps a live dashboard message updated.
- **PlingBotWeb** — a small web dashboard (`localhost:5050`) showing the whole coupon, a live event feed, and a per-match view with statistics, full event history and lineups.
- **TipsScraper** — scrapes a coupon (matches, odds, betting percentages) from Svenska Spel into the JSON file PlingBot reads.
- **TeamIdFetcher** — one-off utility to fill in missing team IDs in the local team registry.

## Requirements

- .NET 9
- Discord bot token with message/channel permissions
- [API-Football](https://www.api-football.com/) API key

## Setup

Create a `.env` file in the project root:

```
DISCORD_TOKEN=your_bot_token
DISCORD_CHANNEL_ID_TEST=channel_id
DISCORD_CHANNEL_ID_LIVE=channel_id

FOOTBALL_API_URL=https://v3.football.api-sports.io
FOOTBALL_API_KEY=your_api_key

GAME=Stryktipset
CHANNEL_MODE=TEST
```

| Variable | Required | Description |
|---|---|---|
| `DISCORD_TOKEN` | ✓ | Bot token |
| `DISCORD_CHANNEL_ID_<MODE>` | ✓ | Channel to post announcements in, one per `CHANNEL_MODE` value you use (e.g. `DISCORD_CHANNEL_ID_TEST`, `DISCORD_CHANNEL_ID_LIVE`) |
| `FOOTBALL_API_URL` | ✓ | API-Football base URL |
| `FOOTBALL_API_KEY` | ✓ | API-Football key |
| `GAME` | — | `Stryktipset` (default), `Topptipset` or `Europatipset` |
| `CHANNEL_MODE` | — | Selects which `DISCORD_CHANNEL_ID_<MODE>` to post in (default `TEST`) |
| `COUPON_DATE` | — | Force a specific coupon date (`YYYY-MM-DD`). Without this, the bot automatically finds the most recent coupon that actually exists, going back day by day |
| `MODE` | — | Set to `VERSUS` to enable multi-player comparison mode |
| `API_MIN_CALL_INTERVAL_MS` | — | Advanced: minimum gap between API calls in milliseconds. The bot learns the real rate limit from the API itself, this is just a fallback before that happens (default `300`) |

## Running

The Discord bot needs a coupon scraped first, then can be started per game and channel mode:

```
scripts\scraper\start-scraper.bat        (or one of the player-specific scraper scripts)
scripts\stryktipset\live.bat             (or europatipset / topptipset)
```

The web dashboard runs independently and just reads whatever coupon JSON was generated most recently:

```
scripts\start-web.bat
```

Or manually:

```
dotnet run --project src/PlingBot/PlingBot.csproj
dotnet run --project src/PlingBotWeb/PlingBotWeb.csproj
```

The coupon JSON file (`src/PlingBot/json/`) is generated by [TipsScraper](src/TipsScraper/) and must exist before starting PlingBot.

## Commands

| Command | Description |
|---|---|
| `!events <n>` | Show all events for match #n (goals, cards, subs) |
| `!stats <n>` | Show live statistics for match #n |
| `!status` | Show current correct picks count |
| `!procent <n> <1%> <X%> <2%>` | Update betting percentages for match #n |
| `!refresh` | Rebuild the live dashboard |
| `!hjälp` | List available commands |

The web dashboard covers the same ground visually — click any match row to open its Statistik / Händelser / Laguppställning tabs.
